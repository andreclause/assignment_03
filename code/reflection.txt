I learned that Streamlit reruns an app from top to bottom after every interaction, so ordinary variables are reset. Values that must persist, such as the processed-file and package counts, belong in `st.session_state`. I also learned that an uploaded file remains selected across reruns, so processing must be gated by the `st.button("Process")` return value; otherwise, the same file can be counted more than once. Keeping parsing in `packaging_parser` and writing the parsed package data with `json.dump` kept the app's responsibilities clear.

The part I found confusing was distinguishing "a file is selected" from "the user just clicked Process." The file uploader can keep returning the same file, while the button is true only on the rerun caused by that click. To practice this pattern, I will trace a sequence of upload, click, and unrelated reruns, recording when the button value changes and verifying that session-state counts change only once per click.
